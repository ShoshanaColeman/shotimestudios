# Sho Time Studios — shotimestudios.com

Portfolio site for Shoshana Coleman (wildlife & conservation photography, plus client sessions).

Plain HTML, CSS and JavaScript, with no build step. It is served as-is by GitHub Pages.

## Pages
- `index.html` — Home / About
- `projects.html`, `pantanal.html`, `far-north-queensland.html` — conservation projects
- `galleries.html` and `galleries-<country>.html` — country galleries
- `video.html` — South Africa showreel (clips in `video/`)
- `sessions.html`, `sessions-<type>.html`, `sessions-book.html` — client sessions
- `contact.html`

## Photos
- Country galleries, Pantanal and Far North Queensland photos are stored as published.
- Sessions gallery photos are web-size copies (3200 px on the long edge, JPEG quality 90). Originals are kept offline.
